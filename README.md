# Nicsite

Responsive Greek-language digital magazine with article cards, topic filters, search, dark mode, and a readable article dialog.

## Files
- `index.html` — homepage and page structure
- `styles.css` — visual design and responsive layout
- `script.js` — sample articles, search, categories, theme switch, and article reader

## Publish with GitHub Pages
1. Open **Settings** for this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The expected address is `https://fanis2025.github.io/Nicsite/`.

## Editing articles
The sample articles are currently stored in the `articles` array in `script.js`. Edit their Greek text and metadata there, then commit the change. This is a static site: there is no secure online admin panel or database yet.

The contact email and sample article content are placeholders and should be updated before public promotion.
